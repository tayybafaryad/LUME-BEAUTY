# ✨ Lume Beauty

**Lume Beauty** is a modern and elegant e-commerce website designed for beauty and skincare products. The website provides a smooth and user-friendly shopping experience where customers can explore a variety of skincare products such as serums, moisturizers, cleansers, and other beauty essentials.

## 🌸 About the Project

Lume Beauty is a front-end e-commerce project created to showcase a beauty brand with a clean, attractive, and responsive design.

The website focuses on providing customers with an easy way to browse beauty products, discover skincare essentials, and interact with a modern online store interface.

## 🛍️ Products

Lume Beauty includes different categories of beauty and skincare products, including:

* ✨ Face Serums
* 💧 Moisturizers
* 🧴 Cleansers
* 🌿 Skincare Essentials
* 💕 Beauty Products
* 🌸 Other Personal Care Products

## 🚀 Features
